## Capability
Automatically compensate playback loudness when current, complete analysis and a safe output path are available.

## Semantics
Loudness normalization is a Playback capability with build-wide report eligibility and a fixed gain policy defined by its normative contract. It applies per track only when the report represents the current catalog and the output can safely apply the policy. Normalization is subordinate to ordinary playability.

## Rules
- Report eligibility is all-or-nothing for the current resource build.
- Eligible measurements are constrained by the accepted target and peak-safety policy.
- Missing measurements, ineligible reports, unsupported output, and normalization failure result in ordinary playback without compensation.
- Normalization failure cannot make a playable track unavailable.

## Edge Cases
A peak constraint may limit compensation below the loudness target. A track may require negative gain. A report that is valid for another catalog build cannot partially normalize the current catalog.
