## Capability
Expose durable project/content-use context through About, proactively present it once on a browser/device's first recorded visit, and keep it manually accessible afterward.

## Semantics
About is a formal user-facing disclosure capability. Its required information is semantic rather than verbatim: it must identify Maple Pod as a fan-made MapleStory BGM player, provide music metadata/source context, state personal-listening/non-commercial-use intent, provide a copyright-owner contact path, state non-affiliation with game development/operation organizations, and expose the running build identity. First-visit presentation occurs once per browser/device until Factory Reset or storage clearing resets onboarding state. Dismissal is local-only and is not portable Saved Data.

## Rules
- Proactively present About on the first recorded visit for a browser/device.
- Persist dismissal locally so later normal visits do not reopen it automatically.
- Do not include first-visit dismissal state in portable Saved Data.
- Normal Reset Saved Data must preserve the dismissal/onboarding state.
- Factory Reset must clear the dismissal/onboarding state.
- Keep About manually accessible from Settings after dismissal.
- Required disclosure semantics include project identity, metadata/source context, personal/non-commercial-use intent, copyright-owner contact path, non-affiliation, and running build identity.
- Displayed build identity must correspond to the running build.
- Exact prose, organization names/examples, layout, storage key, and dialog implementation are non-normative so long as required semantics remain clear and non-misleading.

## Edge Cases
A fresh browser profile or cleared storage is a first recorded visit and should receive proactive disclosure again. Importing portable Saved Data must not suppress the notice on a new device. Factory Reset should restore first-visit behavior; normal Saved Data reset should not. A missing/unavailable build identifier must not be silently replaced with an unrelated value.

## Reverse-spec evidence
Observed implementation and explicitly accepted during About review. The current English copy is evidence of semantics, not immutable legal wording.
