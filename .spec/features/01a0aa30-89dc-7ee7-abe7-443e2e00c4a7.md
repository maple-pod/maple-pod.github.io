## Capability
Provide generic application-shell offline reuse and a user-controlled update lifecycle for the web app.

## Semantics
The application may expose generic offline shell readiness and update readiness as separate user-visible states. A ready update does not change the current page until the user chooses to reload. Generic shell readiness is independent from verified Music and World Map offline readiness.

## Rules
- Supported browsers may receive generic offline shell behavior and a readiness indication.
- A newer application version is surfaced as an update choice rather than an automatic disruptive switch.
- Dismissing the update choice leaves the current session running.
- Generic shell state cannot satisfy content-specific offline contracts.

## Edge Cases
Browsers without the supported capability continue as ordinary web applications. Generic cached content may be useful without proving that any specific music or map content is ready offline.
