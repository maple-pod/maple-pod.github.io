## Capability
Provide a PWA application shell with generic offline reuse and a user-controlled service-worker update lifecycle.

## Semantics
PWA/app-shell offline support is a formal Maple Pod capability where the platform supports service workers. Generic app-shell readiness must be surfaced to the user, but it represents only the shell/runtime cache capability. When a newer application version is ready, Maple Pod must notify the user and must not force a disruptive reload solely because the update exists. Version switch occurs only after explicit user Reload. Explicit Music and World Map offline readiness remain separate contracts and cannot be inferred from generic PWA cache state.

## Rules
- Register PWA/service-worker capability on supported platforms.
- Prepare an application shell/runtime cache sufficient for supported generic offline reuse.
- Surface a user-visible app-shell offline-ready state.
- Surface a user-visible update-ready state when a newer deployed app version is available.
- Do not force page reload/version switch solely because an update is ready.
- Require explicit user Reload to adopt the ready update in the current page/session.
- Closing/dismissing an update notice must not itself reload the page.
- Generic PWA cache readiness must not satisfy Music offline-ready or World Map offline-ready contracts.
- Exact Workbox handlers, cache names, TTLs, entry counts, precache patterns, and registration-library mechanics are non-normative.

## Edge Cases
If service-worker support is absent, Maple Pod degrades to ordinary web-app behavior. If update detection succeeds while playback or other work is active, the current page remains in control until the user chooses Reload. Generic cache availability may include some content resources, but accidental cache presence is not evidence that explicit offline integrity/readiness requirements are satisfied.

## Reverse-spec evidence
Observed in the Vite PWA configuration and reload prompt. Product review intentionally promoted user-visible readiness and explicit reload consent while keeping Workbox strategy details as implementation mechanisms.
