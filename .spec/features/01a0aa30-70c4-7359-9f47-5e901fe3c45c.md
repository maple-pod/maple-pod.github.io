## Legacy Feature notes

## Capability
Project one active playback session onto supported keyboard, system-media, and compact auxiliary player surfaces.

## Semantics
Auxiliary surfaces are alternate views or controls for the established player, not separate playback products. They share current music, queue, position, and transport semantics. Active listening may request an exit safeguard; paused playback does not acquire that safeguard solely from having a session.

## Rules
- Supported auxiliary controls delegate to the active Playback contract.
- Keyboard handling respects the accepted focus and event eligibility rules.
- A supported compact auxiliary surface returns to the same session when closed.
- Unsupported platform capabilities do not block primary playback.

## Edge Cases
Interactive or editable focus suppresses the keyboard surface where required. Closing an auxiliary surface must not fork or destroy the queue. Pending transitions remain governed by the established playback session.

## Legacy Requirement notes: Auxiliary playback-control consistency

## Contract
Maple Pod must expose the active playback session through three auxiliary control surfaces where the platform supports them: Space keyboard toggle, browser Media Session controls, and Document Picture-in-Picture. These surfaces must delegate to one shared active playback queue/session and must not create independent playback state.

The Space shortcut must toggle playback only for an unmodified, non-repeated Space key event when the focused target is not interactive or editable. Keyboard handling must not hijack ordinary form/editing interactions.

Media Session must describe the established current track and must route supported play, pause, previous, next, and seek actions through the same playback semantics used by the primary player. Document Picture-in-Picture must present the same player/session rather than a separate queue or duplicate playback engine.

While playback is actively playing, Maple Pod must request the browser-provided unload confirmation safeguard before page close/navigation when that browser surface is available. Paused playback must not require this safeguard solely because a session/current track exists.

Lack of platform support for Media Session, Document Picture-in-Picture, or unload confirmation must degrade by omitting that auxiliary behavior without preventing ordinary playback.

## Rationale
Auxiliary controls are alternate interaction surfaces, not separate playback products. A single-session rule prevents queue/current-track divergence, while conservative Space handling avoids interfering with ordinary UI interaction. The active-only unload safeguard protects ongoing listening without prompting users unnecessarily while paused.

## Verification
Exercise Space on the page body, interactive controls, editable controls, with modifier keys, and with key repeat. Exercise Media Session metadata plus play/pause/previous/next/seek actions. Open and close Document Picture-in-Picture and verify the same queue/current track/session persists. Attempt page unload while actively playing and while paused. Verify unsupported platform features do not block primary playback.
