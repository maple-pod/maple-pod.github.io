## Capability
Project the active playback session onto keyboard, browser Media Session, and Document Picture-in-Picture surfaces without creating separate playback semantics or independent session state.

## Semantics
Space toggles playback only for unmodified, non-repeated key events outside interactive/editable focus. Media Session mirrors the established current track and delegates play/pause, previous, next, and seek to the active player. Document Picture-in-Picture presents the same player/session when supported. While playback is actively playing, Maple Pod requests browser unload confirmation; paused playback does not.

## Rules
- Space keyboard toggle is a formal playback surface.
- Space must not toggle from interactive/editable controls.
- Modified Space events and repeated keydown events must not toggle playback.
- Media Session is a formal playback surface when supported by the platform.
- Media Session metadata describes the established current track, not a separate candidate/session.
- Media Session actions delegate to the same queue/session semantics as the primary player.
- Document Picture-in-Picture is a formal playback surface when supported by the platform.
- Document Picture-in-Picture hosts the same player/session rather than cloning an independent session.
- Active playback requests the browser unload safeguard; paused playback does not.
- Unsupported auxiliary platform capability must not block primary playback.

## Edge Cases
Focus inside text input, contenteditable, buttons, links, sliders, or other interactive controls suppresses the Space shortcut. Holding Space must not cause repeated play/pause oscillation. Closing the Picture-in-Picture window must not destroy or fork the active playback session. Media Session actions received while a track transition is pending remain governed by the established Playback contract.

## Reverse-spec evidence
Observed implementation and explicitly accepted during Playback auxiliary review. The surface set, Space binding/suppression, unload safeguard, and single-session consistency are normative; browser-specific APIs and DOM movement details remain implementation mechanisms.
