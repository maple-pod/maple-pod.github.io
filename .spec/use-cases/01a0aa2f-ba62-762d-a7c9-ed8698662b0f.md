## Preconditions
Appearance settings are available and the application may have a background catalog.

## Main Flow
1. The user chooses a theme preference and a background preference.
2. Maple Pod applies the choices and responds to later changes in the relevant system preference.
3. When automatic background presentation is selected, Maple Pod changes among eligible backgrounds over time.
4. The user reloads or returns later and sees the accepted appearance preferences still applied.

## Alternate & Failure Flows
- A selected background that is unavailable is rendered safely without breaking the rest of the application.
- An empty or unavailable background catalog leaves the application usable.

## Observable Outcomes
Theme and background choices affect the visible application, system-driven appearance changes are reflected, and temporary background unavailability does not destroy the user's saved choice.
