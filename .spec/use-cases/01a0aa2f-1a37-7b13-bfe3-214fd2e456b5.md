## Preconditions
A playlist can be displayed with resolvable music metadata.

## Main Flow
1. The user opens a playlist and chooses zero or more available marks.
2. Maple Pod narrows the visible tracks according to the selected marks.
3. The user may locate a known music item in a target playlist.
4. Maple Pod navigates to the target playlist context and reveals the located item without changing the playlist.

## Alternate & Failure Flows
- A filter with no matches shows a no-results state distinct from an empty playlist.
- An unknown playlist or non-member target cannot be located and causes no membership change.
- If an active filter would hide a successfully located item, Maple Pod adjusts the presentation so the item is visible.

## Observable Outcomes
Filtering changes only the current presentation. Leaving the playlist or reloading clears the temporary filter, and a successful locate action leaves membership/order unchanged while making the target reachable.
