## Preconditions
The maintainer has inputs for one requested world-map snapshot and the related music catalog.

## Main Flow
1. The maintainer requests a preview or production publication for the exact snapshot identity.
2. The publication process assembles the snapshot and validates it as a complete, consumable artifact.
3. A fully verified production snapshot is made selectable in the catalog.
4. Published snapshots are revalidated as part of later resource maintenance.

## Alternate & Failure Flows
- Preview, partial, incompatible, or inconsistent output remains unavailable for production selection.
- Missing topology or resource integrity is reported as unresolved or invalid rather than repaired into a different map.
- A snapshot that fails later verification loses selectability.

## Observable Outcomes
Users can select only a fully verified production snapshot for the requested identity; failed publication or revalidation does not silently expose a different or stale snapshot.
