## Preconditions
A selectable world-map snapshot can be opened and its offline controls are available.

## Main Flow
1. The user requests offline preparation for the selected snapshot.
2. Maple Pod shows progress while the snapshot is being prepared.
3. The user may cancel, retry a failed or incomplete preparation, or remove saved snapshot data.
4. Maple Pod reports the snapshot ready only when the Offline World Map contract is satisfied.

## Alternate & Failure Flows
- Failure or incomplete preparation is visible and is not reported as ready.
- A cancelled or failed preparation can be retried directly.
- Data for an older or otherwise different snapshot revision does not satisfy the current readiness state.

## Observable Outcomes
The user can distinguish preparing, failed/incomplete, ready, and removed states for the selected world-map snapshot and can recover from a failed preparation without first removing it.
