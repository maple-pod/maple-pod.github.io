## Actor
A person returning to Maple Pod on a browser or installed PWA.

## Goal
Open Maple Pod through a reusable application shell during temporary connectivity loss and adopt newly deployed app versions without an unexpected forced reload.

## Value
Keep the web app resilient to connectivity changes and updates while preserving user control over disruptive reloads.

## Reverse-spec evidence
Observed in `vite.config.ts` and `src/components/PwaReloadPrompt.vue`. Product review explicitly accepted PWA/app-shell offline support as a formal capability, user-visible app-shell offline readiness, explicit user-triggered reload for updates, and strict separation between generic PWA cache readiness and explicit Music/World Map offline readiness.
