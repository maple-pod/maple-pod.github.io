MSE background audio test

This page uses one native <audio controls> element whose src is assigned once to one MediaSource object URL. Five independent WebM/Opus tracks are appended to one SourceBuffer in sequence mode before playback starts.

It does not load the Maple Pod Vue application, does not configure Media Session, and does not replace audio.src between tracks.

Test

  1. Wait until the status says the entire MSE timeline is ready.
  2. Press Play using the browser's native audio controls.
  3. Background the browser or lock the screen.
  4. Leave it playing across several track boundaries.
  5. Observe whether playback stops and whether the browser media notification disappears.
