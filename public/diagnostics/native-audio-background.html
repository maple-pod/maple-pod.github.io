Native audio background test

This page intentionally uses one native <audio controls> element and one media URL. It does not load the Maple Pod Vue application, does not replace the source, and does not configure Media Session.

The single WebM/Opus file is approximately 11 minutes long and concatenates these five tracks without audio re-encoding:

  1. Dragon Dream
  2. Floral Life
  3. Go Picnic
  4. Rest N Peace
  5. Fairy Tale

Test

  1. Press Play using the browser's native audio controls.
  2. Background the browser or lock the screen.
  3. Leave it playing past the point where Maple Pod normally stops.
  4. Observe whether playback stops and whether the browser media notification disappears.
