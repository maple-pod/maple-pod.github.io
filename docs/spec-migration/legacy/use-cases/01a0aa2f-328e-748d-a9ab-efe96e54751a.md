## Preconditions
Music metadata is available and offline controls can be shown for a music item or saveable playlist.

## Main Flow
1. The user requests offline availability for an individual music item or the current members of a saveable playlist.
2. Maple Pod shows progress while preparation is active.
3. The user may cancel, retry a failed or incomplete request, or remove saved offline content.
4. Maple Pod reports the item ready only when the Offline Music contract is satisfied.

## Alternate & Failure Flows
- Failure or incomplete preparation is visible and is not reported as ready.
- A cancelled or failed request can be retried directly.
- Content that no longer matches the current catalog representation is not treated as ready.

## Observable Outcomes
The user can distinguish active, cancelled, failed/incomplete, ready, and removed outcomes for offline music. Bulk preparation follows the playlist membership captured by the request while readiness remains an item-level outcome.
