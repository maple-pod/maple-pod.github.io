## Preconditions
The world-map catalog can be loaded and at least one selectable snapshot is available.

## Main Flow
1. The user opens World Map or requests a snapshot.
2. Maple Pod resolves a snapshot according to the World Map selection contract and loads its manifest before committing a switch.
3. The user navigates roots, breadcrumbs, links, and places within the selected map.
4. Maple Pod presents place names for the user's locale and exposes associated music through the normal Playback experience.
5. The user may retry a failed snapshot or node load.

## Alternate & Failure Flows
- An invalid or unavailable snapshot request is handled by the selection contract and does not fabricate a target.
- A failed switch retains a previously usable map context; an initial failure exposes an error and retry path.
- Missing topology targets remain visibly unresolved or unavailable.

## Observable Outcomes
World Map presents one committed snapshot at a time, preserves a usable context through recoverable failures, exposes navigable places and localized labels, and does not invent missing topology.
