## Preconditions
A playback session exists and the browser or device may provide auxiliary control surfaces.

## Main Flow
1. The user toggles playback with the supported keyboard shortcut when focus permits it.
2. The user may control the session from supported system-media controls.
3. The user may open the player in a supported compact auxiliary window and close it later.
4. Maple Pod keeps current music, queue, position, and transport actions consistent across these surfaces.
5. While listening actively, Maple Pod requests the available exit safeguard before page close or navigation.

## Alternate & Failure Flows
- Unsupported auxiliary surfaces remain unavailable while primary playback continues.
- Interactive or editable focus and unsuitable keyboard events do not trigger the shortcut.
- Closing an auxiliary window does not fork or destroy the active playback session.
- Paused playback does not require the active-listening exit safeguard.

## Observable Outcomes
Each supported surface controls or presents the same playback session, and the user can distinguish active-listening protection from ordinary paused-page exit.
