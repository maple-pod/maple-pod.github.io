## Capability
Publish exact world-map snapshots through a versioned, provenance-bound, integrity-checked resource contract.

## Semantics
World-map artifacts declare compatibility versions and a canonical source authority for each exact snapshot identity. A production snapshot is selectable only after complete verification of its canonical graph, runtime resources, assets, provenance, and integrity metadata. Preview output is isolated, revalidation can revoke selectability, and missing topology remains explicit.

## Rules
- Consumers accept supported compatibility versions and fail closed on unsupported versions.
- Canonical and runtime data must agree with the snapshot's declared provenance authority.
- Enrichment may supplement presentation but cannot rewrite canonical identity.
- Preview or partial output cannot become production-selectable.
- A previously selectable snapshot loses selectability when revalidation fails.
- The new publication contract does not generate an unversioned legacy compatibility alias.

## Edge Cases
A valid-looking preview remains non-selectable. A stale artifact is not trusted because it was previously valid. An unresolved graph reference remains unresolved rather than becoming a guessed target.
