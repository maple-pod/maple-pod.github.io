## Rationale

Physical Android testing showed that the fixed single-file native-audio diagnostic can continue in the background while the normal player still stops. This makes per-track source/session replacement a stronger suspect than a blanket Android background-audio prohibition. An MSE diagnostic can preserve one `HTMLAudioElement` source identity while still crossing real catalogue track boundaries.

## Sources

- Maintainer physical-device report: the approximately 11-minute fixed single-file diagnostic did not appear to stop in the background.
- Media Source Extensions defines `SourceBuffer.appendBuffer()` for appending media segments and `SourceBuffer.mode = "sequence"` for playback ordered by append order.
- Desktop Chromium POC with the current resource catalogue accepted five independent WebM/Opus files into one sequence-mode SourceBuffer when the total compressed data stayed below the browser's SourceBuffer quota.

## Changes

- Replace `/diagnostics/native-audio-background.html` with an MSE-based diagnostic while retaining one native `<audio controls>` element.
- Assign `audio.src` exactly once to one `MediaSource` object URL and never replace it between tracks.
- Fetch and append five existing WebM/Opus catalogue files to one `SourceBuffer` in `sequence` mode before exposing playback controls.
- Use a five-track set totaling about 9 minutes 20 seconds and 8.33 MB so Chromium can pre-buffer the complete timeline without runtime eviction.
- Keep the diagnostic outside the Vue application runtime and do not configure Media Session.

## Verification

Result: passed

- Desktop Chromium reports `MediaSource.isTypeSupported('audio/webm; codecs="opus"')` true for the diagnostic format.
- Five independent catalogue files append successfully to one sequence-mode SourceBuffer with a continuous buffered range from 0 to 560.005 seconds.
- After all five appends, `MediaSource.readyState` reaches `ended`, the media element reports a 560.005-second duration, and its source remains one `blob:` MediaSource URL.
- The selected five inputs total approximately 8.33 MB; a separate trial with the original larger five-track set reproduced Chromium's SourceBuffer quota limit on the fifth append, so the diagnostic does not rely on background-time buffer eviction.
- Physical Android background playback across the MSE track boundaries remains intentionally pending the maintainer's deployed-device test.
