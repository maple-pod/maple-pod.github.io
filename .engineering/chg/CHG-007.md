## Rationale

The maintainer observed that the experimental Web Audio playback path substantially reduced the remaining audible pop during track changes and authorized promoting it to permanent default behavior. Loudness normalization should therefore stop being an opt-in preference while the existing media element remains available as the playback source and compatibility fallback.

## Sources

- Maintainer decision on 2026-09-09 to remove the Experimental toggle and make the Web Audio/loudness-normalized playback behavior permanent after observing a significant reduction in track-switch pops.
- Existing REQ-012 click-free switching contract and the production behavior introduced by CHG-006.

## Changes

- Modified REQ-013 so valid per-track loudness normalization is automatic default behavior rather than a persisted Experimental preference.
- Modified ADR-008 so the Web Audio gain graph is attempted for every playback session on supported browsers, independent of loudness metadata availability, while retaining `HTMLAudioElement` as the media source and fallback.
- Removed the Experimental settings UI and the persisted `experimentalLoudnessNormalization` preference from current saved-data types/defaults/import schema.
- Kept invalid/missing loudness metadata and Web Audio setup failure as non-fatal bypass/fallback cases.
