## Rationale

Versioned World Map snapshots make the old multi-locale name list inside each hotspot popover redundant, while the established desktop interaction already activates a hotspot directly on click. The explicit action remains necessary on touch/non-hover input because that interaction is intentionally two-step. Snapshot selection should also behave like a user preference when entering without route state, and the native `WorldMap` root is the intended neutral root instead of manifest ordering.

The top-bar dropdown anchoring fix in CHG-024 intentionally replaced nested Reka tooltips with locally anchored tooltip content for Downloads and Settings. The World Map entry still used the older Reka tooltip path, and the locally anchored dropdown tooltips could be painted below the following backdrop-filtered content surface. The three top-bar actions therefore need one shared trigger-tooltip primitive plus an explicit top-bar stacking layer.

## Sources

- Maintainer feedback for the current World Map interaction and presentation pass.
- REQ-015 routed World Map navigation, hotspot interaction, and top-bar tooltip requirements.
- REQ-016 versioned snapshot selection and route identity requirements.
- CHG-024 findings that nesting a Reka tooltip around `DropdownMenuTrigger` breaks the dropdown's Popper anchor.
- Current selectable snapshot catalog and manifests, where `WorldMap` is available as a root and selectable GMS versions can be ordered by catalog version.

## Changes

- Persist the last selected snapshot locally; route-less entry restores it when still selectable, otherwise chooses the newest selectable GMS snapshot. Explicit route selection remains authoritative and explicit invalid/non-selectable routes keep the catalog-default fallback.
- Default root-less/invalid-root entry to `WorldMap`, with a defensive first-root fallback only when a snapshot lacks that root.
- Remove repeated alternate locale/version name rows from hotspot popovers while retaining the resolved location name as the title and contextual BGM/shared-point details.
- Hide hotspot action buttons on hover-capable desktop input, where hotspot click already navigates or plays directly; retain full-width two-step actions on touch/non-hover input and render those actions as translucent blur-glass controls.
- Add one reusable lightweight top-bar trigger tooltip for World Map, Downloads, and Settings without introducing a nested Reka Popper context; layer the header above the main content so those locally anchored tooltips are not occluded.
