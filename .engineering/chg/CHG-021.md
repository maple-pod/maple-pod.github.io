## Rationale

Long-running physical Android use of the production bounded-MSE path still produced an occasional stop after the fixed, dynamic, and bounded MSE diagnostics had otherwise demonstrated better source-session continuity than per-track source replacement. The maintainer chose to stop investing further browser-specific buffering work, restore the simpler direct `HTMLAudioElement.src` web behavior, and keep the higher-level player independent enough that a future Cordova/native playback engine can replace the transport without duplicating queue, controls, persistence, history, or UI state.

## Sources

- Maintainer physical-device report after production MSE integration: playback stopped once after extended listening.
- Maintainer decision to restore direct `audio.src` switching and consider a future Cordova application with a replaceable playback backend.
- CHG-014 through CHG-017 and CHG-020, which retain the diagnostic evidence and production MSE experiment history.
- Browser verification in this change showing direct Dragon Dream → Floral Life → Go Picnic source replacement while queue, Media Session metadata, ended handling, and seek position updates remained functional.

## Changes

- Introduce ADR-010 defining a narrow playback-backend boundary between logical player orchestration and the concrete media transport.
- Add `AudioPlaybackBackend`, a default HTML-audio adapter, and a backend composition/factory seam without introducing a generic plugin framework or selecting a Cordova implementation.
- Restore `useAudioPlayer` to last-request-wins per-track source loading and remove production MSE timeline, buffering, and queue-reconciliation behavior.
- Remove the MSE-only queue synchronization API and production `useMseAudioPlayback` controller while retaining standalone MSE diagnostics and their engineering history.
- Route ended and seeked notifications through the backend contract so `useAudioPlayer` and browser Media Session integration no longer require direct access to an `HTMLAudioElement`.
- Update ADR-008, REQ-003, REQ-004, and REQ-012 to describe the direct-source web backend and transport-independent player state.
