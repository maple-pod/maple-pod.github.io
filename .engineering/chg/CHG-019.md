## Rationale

Finalize the maintainer-accepted World Map routed UI behavior after successful real-device verification, including the missing mobile dismissal rule for its deliberate two-step touch interaction.

## Sources

- Maintainer confirmation that the routed World Map UI behaves correctly in real-device testing.
- Maintainer follow-up that mobile World Map interaction must also dismiss an open popover when tapping outside it.

## Changes

- Activate `REQ-015` after acceptance and real-device verification.
- Extend `REQ-015` so touch/non-hover hotspot interaction remains two-step and an outside tap dismisses the active popover.
- Add document-level non-hover outside-pointer dismissal while excluding World Map hotspots and popover content from dismissal.

## Verification

Result: passed

- Mobile/touch browser verification confirmed first-tap popover opening without immediate navigation, popover-internal interaction staying open, explicit `Open` navigation, spot `Play` behavior, and outside-tap dismissal.
- Desktop browser verification confirmed hover hotspot to popover handoff remains open and closes after leaving both regions.
- `pnpm lint` passed.
- `pnpm type-check` passed.
- `pnpm build` passed.
- `git diff --check` passed.
- `pnpm exec ef validate --scope snapshot --format json --no-input` passed with zero diagnostics before finalization.
