## Rationale

Implement the maintainer-approved REQ-017 World Map behavior while preserving the existing progressive snapshot model, 44px semantic interaction baseline, direct desktop actions, and structured runtime link boundary. The implementation addresses the observed contain-fit overflow, desktop title-only popover spacing, missing glass treatment, and DOM-order interception between dense generated spot targets without changing the resources schema or treating base artwork/text as navigation data.

## Sources

- `REQ-017` — approved requirement for contained artwork, deterministic spot interaction, and structured-link-only navigation.
- `REQ-011` — 44px interaction baseline and prohibition on overlapping generated hit areas intercepting adjacent controls.
- `REQ-015` — World Map routed interaction, desktop direct actions, and touch popover behavior.
- `REQ-016` — published `hitRect`/`hitPath` geometry and snapshot-safe World Map runtime data.
- `DESIGN.md` / `pika.config.ts` — `surface-card` glass surface and 16px backdrop blur contract.

## Changes

- Updated `src/views/WorldMap.vue` to size the artwork with its published aspect ratio, a size container, native-size ceiling, and simultaneous width/height containment so it cannot extend into the persistent player.
- Routed pointer/touch spot selection through a local map-level geometry arbiter: published spot `hitRect` records are checked first; geometry-less points use nearest-point arbitration within the 44px baseline envelope, with geometry/area and stable spot ID tie-breakers. Existing 44px semantic buttons remain focusable and keyboard-operable while their overlapping generated rectangles no longer intercept pointer input by DOM order.
- Removed the unconditional popover title bottom margin and changed the popover surface to the established translucent `surface-card` token with `blur(16px)`. Desktop still omits the action button; detail rows retain their content-driven spacing.
- Kept World Map navigation sourced from existing structured `links`/geometry data only; no BaseImg/base-artwork inference was added.
