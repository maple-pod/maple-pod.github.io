## Rationale

The PROJECT Terminology table was left empty at bootstrap. The codebase has an established domain vocabulary (music, mark, playlist variants, saved user data, hash actions, offline music, playing queue) that the engineering files already use informally; recording it makes those terms canonical and prevents drift (e.g. "track"/"tag" creeping in where code says "music"/"mark").

## Sources

- Direct maintainer decision (2026-08-10): the maintainer reviewed the proposed candidate table of eleven terms and accepted all of them ("全部加入").
- Code evidence for each term: `src/composables/useMusicStore.ts` (music, mark, playlist, custom playlist, Liked, offline music), `src/composables/useSavedUserData.ts` (saved user data), `src/schemas/` (hash action, saveable playlist), `src/composables/useAudioQueue.ts` (playing queue), `vite.config.ts` dev proxy (resource host).

## Changes

- Added eleven rows to the `## Terminology` table in `.engineering/PROJECT.md`: music, mark, playlist, custom playlist, Liked, saved user data, hash action, saveable playlist, resource host, offline music, playing queue.
