## Rationale

Record the maintainer-accepted World Map behavior already implemented on `poc/world-map-ui` before formal integration: progressive runtime resources, localized browsing and spot playback, and explicit full offline preparation without an initial canonical document fetch.

## Sources

- Maintainer acceptance in the integration request for the existing `poc/world-map-ui` implementation.
- Existing implementation and validation recorded by branch commit `7ab051a`.
- Existing product intent in `PRD-002`, `PRD-005`, `REQ-009`, and `REQ-011`.

## Changes

- Introduce and activate `REQ-014`, covering manifest-plus-chunk progressive World Map browsing, localization, navigation, spot selection/playback, and accessibility behavior.
- Introduce and activate `ADR-009`, selecting the schema-v1 runtime contract and Cache Storage-based explicit full offline preparation keyed by `manifest.cacheKey`.
- No production-code changes are included in this EF-only transaction.
