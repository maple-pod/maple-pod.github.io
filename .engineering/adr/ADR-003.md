## Context

The app needs consistent theming (light/dark), design tokens, and icon handling in a Vue 3 + Vite build with no runtime style cost.

## Decision

Use PikaCSS, a build-time atomic CSS-in-JS engine, as the single styling system. `pika.config.ts` holds the design tokens (theme colors), preflights, selectors, shortcuts, and icon integration; components style through `pika()` calls and generated atomic classes.

## Alternatives

Not recorded at adoption time. PikaCSS is a first-party project of this repository's author, which the choice reflects.

## Consequences

- Styles are generated at build time with type-checked usage (`pika.gen.ts` is generated and never hand-edited).
- Theme tokens and icons are centralized in `pika.config.ts`.
- Contributors must learn PikaCSS conventions (the `pikacss-use` skill documents them); mainstream utility-framework knowledge does not transfer directly.
