## Context

The product should feel like an installed music app and keep itself current, on static hosting with no release server (ADR-001).

## Decision

Generate the PWA layer with vite-plugin-pwa: the manifest is defined in `vite.config.ts` (the source of truth for app name/description), the service worker is workbox-generated, and registration uses `registerType: 'autoUpdate'` with a reload prompt component (`PwaReloadPrompt`) for applying new versions.

## Alternatives

Not recorded at adoption time; this choice predates EF adoption.

## Consequences

- Users get installability and automatic updates on each deploy to GitHub Pages.
- workbox is currently pinned to 7.4.0 because 7.4.1 pulls an unattested fork prerelease that trips the supply-chain trust policy (POL-001); the pin is documented in `pnpm-workspace.yaml`.
- Service-worker caching behavior is owned by workbox configuration in `vite.config.ts`.
