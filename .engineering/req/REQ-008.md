## Requirement

Any track can be saved for offline playback. Saved audio is stored as blobs in a localforage instance named `maple-pod`; the UI shows a download manager where in-flight downloads can be cancelled and saved tracks can be removed. When a saved copy exists, playback uses it instead of fetching from the network.

## Rationale

The catalog streams from an external host (ADR-001), so explicit per-track downloads are what makes offline listening (PRD-005) possible.

## Acceptance Criteria

- Saving a track stores its audio locally and marks it as available offline in the UI.
- An in-flight download can be cancelled, leaving no partial saved entry.
- A saved track can be removed, freeing its storage.
- A saved track plays from local storage without network access.
