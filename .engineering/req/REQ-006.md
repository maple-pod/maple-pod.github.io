## Requirement

All user data — preferences (theme, background image, volume, muted, random, repeated), the Liked playlist, custom playlists, and play history — is stored under the `maple-pod` key in localStorage, merged with defaults on load, and restored automatically when the app starts. Data imported from outside (URL hash actions) is accepted only after validation against the valibot schemas in `src/schemas/`.

## Rationale

The app has no backend (ADR-001), so the device is the source of truth for user data; schema validation keeps externally supplied data from corrupting it.

## Acceptance Criteria

- Reloading the app restores preferences, Liked, custom playlists, and history without user action.
- Missing fields in stored data are filled from defaults (`mergeDefaults`), so older data keeps working after upgrades.
- Imported saved-user-data payloads are validated against `SavedUserDataSchema` before being applied; invalid payloads are rejected.
- Out-of-range persisted values (e.g. an unknown repeat mode) are normalized to a safe default on load.
