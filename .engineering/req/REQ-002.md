## Requirement

The playlist filter communicates its state to the user: when the current playlist has no marks at all, the filter shows an empty-state message; when the applied filters match zero tracks, the track list area shows a "no results" message; and while any filter is active, the view shows a result count in the form "X/Y tracks".

## Rationale

Without feedback, an empty filtered list is indistinguishable from a broken playlist, and users cannot tell how much of the list a filter hides. Carried over from the original feature plan (EMPTY-01..03).

## Acceptance Criteria

- When the current playlist contains no marks, opening the filter shows an empty-state message instead of an empty list.
- When active filters match zero tracks, a "no results" message is displayed in the track list area. Because marks are derived from the current playlist and filtering uses OR logic, selecting a mark always matches at least one track; this state is only reachable when the playlist contents change while a filter stays active (for example, un-liking the last remaining track of the Liked playlist).
- While at least one mark is selected, a result count "X/Y tracks" is displayed (X = matching tracks, Y = total tracks in the playlist).
