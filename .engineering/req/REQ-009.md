## Requirement

The app ships as an installable PWA: a web manifest (name "Maple Pod", icons, theme color), a workbox-generated service worker registered with `autoUpdate`, and a reload prompt component that lets users apply a newly installed version. Deployed on GitHub Pages, deep links resolve through the `404.html` SPA fallback so any route loads directly.

## Rationale

Installability and offline-capable delivery are core to the product's "always-available player" promise, and GitHub Pages' static hosting requires the 404 fallback for client-side routing.

## Acceptance Criteria

- Browsers offer PWA installation with the manifest identity (name, icons).
- When a new version is deployed, the service worker updates automatically and the user is prompted to reload.
- Opening a deep link (e.g. `/playlists/<id>`) directly loads the app rather than a hosting 404 page.
