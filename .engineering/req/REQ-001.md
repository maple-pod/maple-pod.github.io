## Requirement

The playlist view provides a filter control alongside the playlist dropdown menu: a toggle button (funnel icon) that reflects whether any filter is applied, and a dropdown that lists every unique mark extracted from the current playlist's tracks, each with a checkbox and a track-count badge. Selecting marks filters the visible track list to tracks whose mark matches any selected mark.

## Rationale

Marks are the only categorical dimension on playlist tracks, so they are the natural unit for narrowing a long list. OR logic keeps the interaction simple and predictable; ephemeral state keeps the filter from surprising users on their next visit.

## Acceptance Criteria

- Unique marks are extracted from the current playlist's tracks, listed in order of first appearance.
- Each mark shows a badge with the number of tracks carrying that mark.
- Selecting multiple marks shows tracks matching any selected mark (OR logic); deselecting updates the list reactively.
- With no marks selected, all tracks are shown (default state).
- A "Select all" control selects every mark; a "Clear all" control resets the selection.
- The dropdown closes on outside click; keyboard interaction supports Enter/Space to toggle a mark and Escape to close.
- Filter state clears when the user navigates away from the playlist view or switches playlists.
