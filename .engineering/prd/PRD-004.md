## Problem

User data lives only on each device (PRD-003), so without some transport there is no way to hand a playlist to a friend or move data to another browser.

## User Need

Users want to share a playlist or a specific track with a link, and to carry their saved data to another device, without creating an account.

## Desired Outcome

Everything shareable is encoded into a URL: playlist import links, saved-user-data setup links, and direct-play links that open the app already playing a chosen track after confirmation.

## Success Criteria

- A shared playlist link opens the app and imports the playlist after validation (REQ-007).
- A setup link imports saved user data on the receiving device (REQ-007).
- A direct-play link plays the referenced track after user confirmation (REQ-007).

## Non-goals

- Server-side storage of shared content; the URL itself is the only transport.
- Real-time collaboration or shared editing of playlists.
